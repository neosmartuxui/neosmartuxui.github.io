Framework integration

Use actual browser DOM adapters with Vanilla JS, React and Vue. These are lifecycle wiring examples, not React or Vue component exports.

LOCAL ESM ONLY

Installation boundary

Run npm run build:library:local in the repository and link its private artifacts/library-package directory into your consuming workspace. The local package is @neosmartuxui/library version 0.0.0-local, marked private. It is NOT available from the npm registry. Import @neosmartuxui/library/core, the local styles/core.css, and one canonical Theme stylesheet.

Always supply semantic native markup and manage disposer cleanup on unmount. Keep interactive state owned by the native DOM/adapter, or explicitly synchronize application-owned state with the documented setter. Hardline pressure derives from Theme tokens, never application CSS hacks.

PRIVATE ESM / bindAccordion

Vanilla JavaScript

import { bindAccordion } from '@neosmartuxui/library/core';
const root = document.querySelector('#disclosures');
const dispose = bindAccordion(root, { expansion: 'single' });
// Root must contain semantic triggers and panels from the Core fixture.
// Call dispose() when the host removes the component.
PRIVATE ESM / bindToggle

React (uncontrolled DOM adapter)

import { useEffect, useRef } from 'react';
import { bindToggle } from '@neosmartuxui/library/core';

export function TactileToggle() {
  const button = useRef(null);
  useEffect(() => {
    if (!button.current) return;
    return bindToggle(button.current);
  }, []);
  return <button ref={button} type="button" className="ns-toggle"
                 aria-pressed="false">Bold</button>;
}
// The adapter owns DOM aria-pressed while mounted. Do not also
// control that attribute through React state without explicit sync.
PRIVATE ESM / bindNumberField

Vue 3 (mounted DOM adapter)

<script setup>
import { ref, onMounted, onBeforeUnmount } from 'vue';
import { bindNumberField } from '@neosmartuxui/library/core';

const root = ref(null);
let dispose = null;
onMounted(() => { if (root.value) dispose = bindNumberField(root.value); });
onBeforeUnmount(() => dispose?.());
</script>

<template>
  <div ref="root" class="ns-number-field">
    <label for="quantity" class="ns-number-field__label">Quantity</label>
    <input id="quantity" class="ns-number-field__input"
           type="number" min="0" max="12" step="1" />
    <button type="button" class="ns-number-field__step"
            data-number-field-action="decrement">−</button>
    <button type="button" class="ns-number-field__step"
            data-number-field-action="increment">+</button>
  </div>
</template>
<!-- Input remains native value authority; avoid duplicate Vue state. -->

Validation boundaries

These binders and the private distribution subpath are validated through actual ESM imports and local source packaging, and DOM actions are tested in Chromium. The React/Vue examples are source-backed integration patterns, not separate shipped or runtime-tested framework component packages. Production and public npm release gates remain closed.
